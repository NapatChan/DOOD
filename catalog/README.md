# เพิ่มเสื้อผ้าเข้าแอป DOOD

โยนรูป PNG โปร่งเข้าโฟลเดอร์ที่ถูกหมวด แล้วสั่งคำสั่งเดียว — จบ

## 3 ขั้นตอน

1. **วางไฟล์** ลงในโฟลเดอร์ตามหมวด
   - `catalog/hats/` — หมวก
   - `catalog/shirts/` — เสื้อ
   - `catalog/pants/` — กางเกง

2. **ตั้งชื่อไฟล์** ตามรูปแบบ `ชื่อ__ราคา.png` (ขีดล่าง 2 ตัวคั่นราคา)

   | ชื่อไฟล์ | ได้เป็น |
   |---|---|
   | `เสื้อลินินขาว__590.png` | ชื่อ "เสื้อลินินขาว" ราคา 590 |
   | `01_เสื้อขาว__590.png` | เลข `01_` ข้างหน้า = ลำดับการเรียง (ไม่โชว์ในชื่อ) |
   | `หมวกกวน.png` | ไม่มีราคา → ใช้ราคา default (590) |

3. **สั่ง** `npm run add`

## ระบบจัดการให้อัตโนมัติ

- ✂️ ตัดขอบโปร่งส่วนเกิน (trim) ให้เสื้อผ้าเต็มเฟรม → ต่อกันเป็นชุดสวย
- 🎨 ดึงสีเฉลี่ยของเสื้อผ้าเป็นสี fallback (เผื่อรูปโหลดไม่ขึ้น)
- 📄 อัปเดตข้อมูลสินค้าในแอปให้เอง (`src/data/catalog.generated.ts`)

## ข้อกำหนดรูป

- **มีพื้นหลังก็ได้!** ระบบตัดพื้นหลังให้อัตโนมัติ (รูปโปร่งอยู่แล้วจะข้ามให้เอง) — รองรับ .png .webp .jpg
- จัตุรัส เช่น 1200×1200 (เสื้อผ้าอยู่กลางเฟรม)
- ถ่าย/วางหันหน้าตรง สเกลใกล้เคียงกันในแต่ละหมวด

## แก้ไข/ลบ

- **ลบสินค้า:** ลบไฟล์ออกจาก `catalog/<หมวด>/` แล้วรัน `npm run add` ใหม่
- **แก้ชื่อ/ราคา:** เปลี่ยนชื่อไฟล์ แล้วรัน `npm run add` ใหม่

> ห้ามแก้ `src/data/catalog.generated.ts` ด้วยมือ — มันถูกสร้างใหม่ทุกครั้งที่รัน `npm run add`
