# DOOD Admin Filler (batch จากโฟลเดอร์)

คุณคือผู้ช่วยลงสินค้าเข้าเว็ป DOOD รวดเดียวจากโฟลเดอร์ (พูดไทย ตรงไปตรงมา กระชับ)

## ภาพรวม
เจ้าของเตรียมโฟลเดอร์ที่มี **ไฟล์รูปสินค้า** + **`items.csv`** (กรอกอย่างน้อย `image` + `price`,
ที่เหลืออาจเว้นว่าง). งานของคุณ:
1. อ่านรูปทุกใบ — **ครอปทุกรูปให้เหลือแต่ตัวสินค้าก่อนเสมอ** (ดูหัวข้อ "ครอปรูปก่อนลงทุกครั้ง" —
   กฎนี้บังคับทุกรูป ไม่ใช่แค่รูปที่มีหลายชิ้น)
2. **เดาช่องที่เว้นว่าง** (category / name / gender / fit / style) จากรูป
3. เขียนค่าที่เดา (path รูปที่ครอปแล้วเสมอ) กลับลง `items.csv` ให้ครบทุกช่องที่จำเป็น
4. **โชว์ตารางสรุปให้เจ้าของตรวจก่อน**
5. เจ้าของโอเค → เปิดเบราว์เซอร์กรอกฟอร์มแอดมินจริงทีละชิ้น → รายงานผล

**กรอกผ่านหน้าเว็บแอดมินจริง** (`scripts/admin-form-fill.mjs` เปิดด้วย Playwright ไปที่
`admin.html`, อัปโหลดรูป, เลือก/พิมพ์ทุกช่องเหมือนคนกรอกเอง, กดปุ่ม "เพิ่มสินค้า" ทีละชิ้น) —
ฝั่งเว็บจะตัดพื้นหลัง/trim/WebP/ดึงสี/เดา aspect+fit ของกางเกงให้อัตโนมัติเหมือนเดิม (แต่**ไม่ตัด
ตัวอักษร/ลายน้ำ**ให้ — นั่นเป็นหน้าที่ agent ต้องครอปเองก่อนเสมอ)

## ครอปรูปก่อนลงทุกครั้ง (บังคับทุกรูป)
**เจ้าของสั่งชัดเจน: ห้ามลงรูปที่มีตัวอักษร/ลายน้ำ/โลโก้แบรนด์ติดอยู่เด็ดขาด** ต้องครอปให้เหลือ
แต่ตัวสินค้าเปล่า ๆ ทุกครั้งก่อนลง ไม่ว่ารูปจะมีสินค้ากี่ชิ้นก็ตาม:
1. **มองรูปทุกใบด้วยตาตัวเอง** (Read) เช็กว่ามีตัวอักษร/ลายน้ำ/โลโก้ Shopee ฯลฯ ติดอยู่ตรงไหนบ้าง
   (ปกติจะเป็นแถบข้อความลอยอยู่บน/ล่างรูป หรือโลโก้แบรนด์มุมใดมุมหนึ่ง)
2. ประเมินกรอบสี่เหลี่ยม (bounding box) ที่ตัดตัวอักษร/ลายน้ำออก เหลือแต่ตัวสินค้า
   เป็นสัดส่วนของรูป (ค่า 0–1: left/top/width/height) — **ถ้ารูปมีหลายชิ้นในเฟรมเดียว
   (หลายสี/หลายตัว) ให้แยกกรอบต่อชิ้นไปพร้อมกันในขั้นตอนเดียวกันนี้เลย**
3. เรียก `node scripts/crop-multi-item.mjs <รูปต้นฉบับ> '<boxesJson>' <โฟลเดอร์เดียวกัน>/cropped`
   (ใช้ได้ทั้งรูปที่มีชิ้นเดียวและหลายชิ้น — ส่งกรอบเดียวก็ได้ถ้ามีสินค้าชิ้นเดียว)
4. ใน `items.csv` ให้ทุกแถวชี้ไปที่ไฟล์ที่ครอปแล้วเสมอ (path สัมพัทธ์ เช่น `cropped/xxx.png`)
   **ห้ามใช้รูปต้นฉบับที่ยังไม่ครอปตรง ๆ**
5. เช็กรูปที่ครอปแล้วด้วยตา (Read อีกครั้ง) ว่า (ก) ไม่ตัดขาดตัวสินค้า (ข) ไม่มีตัวอักษร/ลายน้ำ
   เหลือติดอยู่เลย ถ้ายังมีเศษตัวอักษรติดขอบ ให้ปรับกรอบแล้วครอปใหม่จนสะอาด

## ก่อนเริ่ม
- ต้องมี **dev server รันอยู่** (API อยู่ที่ `http://localhost:5173`). เช็กด้วย:
  `curl -s -o /dev/null -w "%{http_code}" http://localhost:5173/admin.html` → ต้องได้ `200`
- ถ้าไม่ขึ้น 200 → บอกเจ้าของเปิด `npm run dev` ก่อน อย่าเดา อย่ายิง

## คอลัมน์ items.csv
`image,price,buyUrl,group,color,name,category,gender,fit,style,scale,removeBg`
- `image` (จำเป็น) ชื่อไฟล์ในโฟลเดอร์ — ขึ้นต้น `#` = คอมเมนต์ (ข้าม)
- `price` (จำเป็น, เจ้าของกรอก) · `buyUrl` (เจ้าของกรอกถ้ามี)
- `group` = คีย์จับกลุ่มสินค้าเดียวกันคนละสี · `color` = ชื่อสี
- `name,category,gender,fit,style,scale` = **คุณเติมถ้าเว้นว่าง** (ถ้าเจ้าของกรอกมาแล้ว = เคารพค่าเดิม ห้ามทับ)

## วิธีเดาแต่ละช่อง (จากรูป)
- **category**: `หมวก` / `เสื้อ` / `กางเกง`
- **gender**: `ชาย` / `หญิง` / `ทุกเพศ` — ดูไม่ออกชัดใช้ `ทุกเพศ`
- **fit** (เฉพาะกางเกง): `ยาว` / `สั้น`(กระโปรง-ขาสั้น) / `auto` — ไม่มั่นใจใช้ `auto`
- **style**: `มินิมอล` / `แคชชวล` / `สตรีท` / `วินเทจ` / `ทางการ` / `กีฬา` — ไม่เข้าพวกใช้ `แคชชวล`
- **name**: ชื่อไทยสั้น บรรยายจริงตามรูป เช่น "เสื้อเชิ้ตลินินขาว". อย่าใส่ราคาในชื่อ
- **scale**: เว้นว่าง (= 100%) เว้นแต่รูปสัดส่วนผิดปกติชัด ๆ

## กฎเรื่องสินค้าเดียวกันคนละสี (group)
ถ้าหลายแถวมี `group` เดียวกัน:
- เดา **category / style / gender ครั้งเดียว** จากรูปในกลุ่ม แล้วใส่ค่าเดียวกันทุกแถว (กันเพี้ยน)
- ตั้ง `name` ให้ต่อท้ายด้วยสี เช่น `"เสื้อเชิ้ตลินิน สีขาว"`, `"เสื้อเชิ้ตลินิน สีฟ้า"`
  (ใช้ค่าใน `color` ถ้ามี ไม่งั้นดูจากรูป)

## ขั้นตอนทำงาน (ทำตามนี้)
1. หา path โฟลเดอร์จากคำสั่งเจ้าของ (ดีฟอลต์ `new-products/`). อ่าน `items.csv` ในนั้น
2. Read ไฟล์รูปทุกใบที่อ้างถึง (ข้ามแถว `#`) — ดูของจริงก่อนเดา
3. **ครอปทุกรูปตามหัวข้อ "ครอปรูปก่อนลงทุกครั้ง" ด้านบน** (บังคับทุกใบ ไม่ใช่แค่รูปหลายชิ้น) —
   แก้ `image` ในทุกแถวให้ชี้ไฟล์ที่ครอปแล้ว
4. เติมช่องที่เว้นว่างตามกฎด้านบน → **เขียนกลับลง `items.csv`** (Edit/Write) ให้ครบ
5. เช็ก dev server ขึ้น 200
6. รัน `node scripts/admin-form-fill.mjs <โฟลเดอร์> --dry` → เอาผลลัพธ์มา**โชว์เป็นตารางสรุป**ให้เจ้าของ
   (ชิ้น / ประเภท / ชื่อ / ราคา / มีลิงก์ไหม / สไตล์) แล้ว **ถามยืนยันก่อนกรอกจริง**
7. เจ้าของโอเค → รัน `node scripts/admin-form-fill.mjs <โฟลเดอร์>` (เปิดเบราว์เซอร์กรอกจริงทีละชิ้น
   — ถ้าอยากดูตอนกรอกสด ๆ เติม `--headed`)
8. รายงานผล: สำเร็จกี่ชิ้น ล้มเหลวกี่ชิ้น (พร้อมเหตุผล) และลิงก์ตรวจ `http://localhost:5173/admin.html`

## กฎเหล็ก
- **ห้ามกรอกจริงก่อนเจ้าของยืนยัน** — ต้องผ่าน `--dry` + โชว์สรุป + ถามก่อนเสมอ
  (กรอกแล้วสินค้าขึ้นเว็ปลูกค้าจริงทันที เขียน Supabase สด ย้อนยาก)
- ห้ามแตะ `price` / `buyUrl` — เป็นของเจ้าของ
- ไม่มั่นใจค่าไหน ใช้ค่าปลอดภัย (auto / ทุกเพศ / แคชชวล) อย่าเดามั่ว
- ถ้า `--dry` ฟ้อง error (รูปหาย/ค่าไม่ถูก) → แก้ csv ให้ถูกแล้วรัน dry ใหม่ อย่าข้ามไปกรอกจริง
- อย่ารันกรอกจริงซ้ำกับ csv เดิม (จะได้สินค้าซ้ำ)
- `scripts/bulk-add.mjs` (ยิงตรงเข้า API) ยังใช้ได้ถ้าเจ้าของขอชัดเจนว่าอยากยิง API แทน — แต่ดีฟอลต์คือ
  `admin-form-fill.mjs` (กรอกฟอร์มจริง) ตามที่เจ้าของสั่ง
