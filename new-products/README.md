# 📦 ลงสินค้าหลายชิ้นรวดเดียว (bulk add)

โยนรูปสินค้าใส่โฟลเดอร์นี้ + กรอก `items.csv` แล้วให้ระบบยิงเข้าเว็ปให้ทีเดียว

## ขั้นตอน

1. **เปิด dev server** ไว้ (ในเทอร์มินัล): `npm run dev`
2. **วางไฟล์รูป** ทั้งหมดลงในโฟลเดอร์ `new-products/` (png / webp / jpg — มีพื้นหลังก็ได้ ระบบตัดให้)
3. **เปิด `items.csv` ใน VSCode** แล้วกรอก 1 แถวต่อ 1 ชิ้น (1 สี = 1 แถว):
   - จำเป็น: `image` (ชื่อไฟล์) + `price`
   - มีก็ใส่: `buyUrl`
   - สินค้าเดียวกันคนละสี: ใส่ `group` ให้เหมือนกัน + ระบุ `color`
   - **ที่เหลือเว้นว่างได้** (`name`,`category`,`gender`,`fit`,`style`) → ให้ AI เดาจากรูปให้
   - แถวที่ `image` ขึ้นต้นด้วย `#` = คอมเมนต์ (ถูกข้าม)
4. บอก Claude: **"ลงสินค้าจากโฟลเดอร์ new-products ให้ที"**
   - AI (agent `dood-admin-filler`) จะอ่านรูป → เติมช่องที่เว้นไว้ → โชว์ตารางสรุปให้ตรวจก่อน → ยิงเข้าจริง

## อยากยิงเองก็ได้ (ถ้ากรอก csv ครบทุกช่องเอง)

```bash
node scripts/bulk-add.mjs new-products --dry   # ลองดูก่อน (ไม่เขียนจริง)
node scripts/bulk-add.mjs new-products         # ยิงจริง
```

## ค่าที่กรอกได้ในแต่ละช่อง

| ช่อง | ค่า |
|---|---|
| `category` | `หมวก` / `เสื้อ` / `กางเกง` |
| `gender` | `ชาย` / `หญิง` / `ทุกเพศ` (เว้น = ทุกเพศ) |
| `fit` | `ยาว` / `สั้น` / `auto` — เฉพาะกางเกง (เว้น = เดาจากรูป) |
| `style` | `มินิมอล` / `แคชชวล` / `สตรีท` / `วินเทจ` / `ทางการ` / `กีฬา` |
| `removeBg` | `auto` (ตัดถ้ายังไม่โปร่ง) / `on` (ตัดเสมอ) / `off` (ไม่ตัด) — เว้น = auto |

⚠️ ยิงแล้วสินค้าขึ้นเว็ปลูกค้าจริงทันที (เขียน Supabase สด) — ตรวจราคา/ลิงก์ให้ดีก่อน
⚠️ อย่ารันสคริปต์ซ้ำกับ csv เดิม จะได้สินค้าซ้ำ (ลบซ้ำได้ในแอดมิน)
